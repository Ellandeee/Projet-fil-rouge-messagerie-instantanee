## Description de la fonctionnalité

Dans notre messagerie instantanée, nous ajoutons un système de personnalisation de l'espace de communication.

À la manière de Twitch, l'utilisateur gagne des points en fonction du temps passé sur une discussion active. Une limite d'inactivité est intégrée afin d'éviter l'accumulation passive de points.

### Éléments personnalisables
Les points accumulés permettent de personnaliser l'interface indépendamment pour chaque contact :
* Fond de discussion
* Cadre de messages
* Cadre de photo de profil
* Typographie et couleurs (police, style, etc.)

---

## Système de classement
Un classement répertorie l'ensemble des points obtenus par contact. Il permet à l'utilisateur d'identifier les personnes avec lesquelles il est le plus actif.
